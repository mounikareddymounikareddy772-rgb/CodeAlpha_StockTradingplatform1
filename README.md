# Stock Trading Platform1

## Project Description

Stock Trading Platform is a Java-based console application developed as part of the CodeAlpha Java Programming Internship.

The project simulates basic stock trading operations, allowing users to view market data, buy and sell stocks, manage their portfolio, and view transaction history.

## Features

- View market data
- Buy stocks
- Sell stocks
- Manage stock holdings
- View cash balance
- Calculate total portfolio value
- View transaction history
- Validate stock quantity and user input
- Track buy and sell transactions

## Technologies Used

- Java
- ArrayList
- HashMap
- Map
- Object-Oriented Programming
- Scanner

## How to Run

1. Compile the Java program.
2. Run `StockTradingPlatform1.java`.
3. Select an option from the menu.
4. View market data or buy and sell stocks.
5. View your portfolio and transaction history.
6. Select Exit to close the application.
